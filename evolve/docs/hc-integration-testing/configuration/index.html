Configuration

The configuration file is JSON and is read from config.json by default. A different file can be selected with -c, -conf, or --conf.

Top-level Fields​

FieldRequiredDescription
ioYesEAS, result database, and report writer configuration.
testsNoWork package requests to run and validations to apply. Defaults to an empty list.
preparationNoReference work package requests to run before the tests. Defaults to no preparation.
definitionsNoReusable metric reductions and existing vintage work packages. Defaults to no definitions.

Example​

{
  "io": {
    "environment": {
      "eas": {
        "host": "staging.dev.zb.energy",
        "port": 443,
        "protocol": "HTTPS",
        "accessToken": "<access-token>"
      },
      "resultsDb": {
        "host": "input-db.staging.dev.zb.energy",
        "port": 5432,
        "name": "hc_endeavour",
        "user": "postgres",
        "pass": "<password>",
        "schema": "public"
      }
    },
    "resultsWriters": {
      "testResultsDb": {
        "host": "127.0.0.1",
        "port": 15432,
        "name": "hc_integration_testing",
        "user": "postgres",
        "pass": "<password>",
        "schema": "public"
      },
      "slackChannel": null,
      "logger": true
    }
  },
  "definitions": {
    "metricReductions": [
      {
        "key": "yearly_average_voltage_delta",
        "metricNames": ["voltage_delta_avg"],
        "filters": [
          {
            "columnName": "time_of_day",
            "constraint": {
              "targetValue": "all",
              "relation": "=="
            }
          },
          {
            "columnName": "season",
            "constraint": {
              "targetValue": "yearly",
              "relation": "=="
            }
          }
        ],
        "aggregations": [
          {
            "aggType": "AVG",
            "ungroupedColumns": []
          }
        ]
      }
    ],
    "vintageWorkPackages": [
      {
        "key": "known_good",
        "workPackageId": "1fed29d8-8c48-4b82-97ed-bf1ffaac1382"
      }
    ]
  },
  "preparation": {
    "referenceWorkPackages": []
  },
  "tests": [
    {
      "workPackageRequest": {
        "workPackageName": "OP1132 test",
        "input": {
          "feederConfigs": {
            "configs": [
              {
                "feeder": "OP1132",
                "years": [2024],
                "scenarios": ["base"],
                "timePeriod": {
                  "startTime": "2023-02-22T00:00:00",
                  "endTime": "2024-02-22T00:00:00"
                }
              }
            ]
          },
          "qualityAssuranceProcessing": true
        }
      },
      "metricValidations": [
        {
          "metricReduction": "yearly_average_voltage_delta",
          "validationMethods": [
            {
              "type": "AgainstReference",
              "referenceWorkPackage": "known_good",
              "relation": "~*=(0.01)"
            }
          ]
        }
      ]
    }
  ]
}

EAS Authentication​

io.environment.eas requires either a static accessToken, or all of clientId, clientSecret, audience, and issuer.

Optional TLS fields:

FieldDefaultDescription
certificatenullCustom certificate material.
verifyCertificatestrueWhether server certificates are verified.

Result Writers​

io.resultsWriters controls where test results are written.

FieldDefaultDescription
loggerfalseWrites test results to the application log.
testResultsDbnullWrites to an integration testing report PostgreSQL database.
slackChannelnullWrites Slack messages using channel, botToken, and optional apiBaseUrl.

Definitions​

definitions.metricReductions is a list. Each entry must have a unique non-blank key, one or more metricNames, optional filters, and at least one aggregation.

Available aggregation types are MAX, MIN, AVG, and SUM.

Available relations are ==, !=, >, >=, <, <=, ~=(epsilon), and ~*=(epsilon).

definitions.vintageWorkPackages is a list of named existing work packages:

{
  "key": "known_good",
  "workPackageId": "1fed29d8-8c48-4b82-97ed-bf1ffaac1382"
}

Preparation​

preparation.referenceWorkPackages is a list of work packages to run before test execution. The resulting work package ID is stored under the entry's key and can be referenced by AgainstReference validations.

{
  "key": "fresh_reference",
  "workPackageRequest": {
    "workPackageName": "reference OP1132",
    "input": {
      "feederConfigs": {
        "configs": []
      }
    }
  }
}

Keys must not be shared between preparation.referenceWorkPackages and definitions.vintageWorkPackages.
