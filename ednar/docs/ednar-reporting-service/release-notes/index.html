[6.2.0] - 2026-07-27​

Breaking Changes​

  • None.

New Features​

  • None.

Enhancements​

  • Rudimentary backwards compatibility for different versions of EDNAR is now available by setting a new EdnarAppServerVersion property in config.
  • DevExpress data bindings and expression bindings are now both supported in DMS DevExpress templates.
  • More complex DevExpress data bindings are now supported, such as CUSTOM_FIELD_10_15_20, as well as bindings with square brackets in them.

Fixes​

  • Authentication calls against EDNAR App Server's REST API now respects the TrustAllCertificates configuration properties when the certificate is untrusted because of a common name/subject alternative name mismatch.
  • EDNAR API Client tokens will now refresh once they expire.
  • null values in the DMS's PERMIT_TEXT table will no longer cause elements of Permit PDFs from the DMS to fail to render.

[5.2.0] - 2024-10-15​

Breaking Changes​

  • Nar HTML report has been reimplemented and needs update to the NarReportTemplate.html file. See notes about NarReportTemplate.

New Features​

  • Word (doc, docm, docx), Excel (xls, xlsx), csv and Email (msg, eml) attachments is now supported.
  • Depot and region are passed in to the NAR Report template.

Enhancements​

  • Nustache tag for ShowingQuestions has been updated to support NAR questions and all checklists (including cusom ones). I.E. for nar questions it is accessible via ShowingQuestions.NAR and for planner checklist it will be ShowingQuestions.PLANNER

Notes​

  • edner-reporting-service.exe.config has changed and will need to be updated. There are no config changes in this release, so just need to copy the config and connection string section from the old version to the new one.

  • NarReportTemplate:

    For creating NAR report, we use Aspose's PDF package to create a PDF from HTML. We noticed that when we updated the version of Aspose PDF package to 22.1 in June 2022 to support flattening PDF annotation, Aspose has introduced a bug that won't free up memory after creating PDF from HTML. Because the bug is still not fixed by Aspose (as of version 24.7), we are changing our implementation to use their HTML package. This package fixes that issue but happens to also have a bug with rendering CSS style for table border-collapse (Aspose PDF version 24.7 has this issue too). Instead of using css to collapse the border, we change it to use the HTML table attribute cellspacing set to 0. Below are the changes made to the template file.
